# AUREVIX — Dashboard User Guide

## Launch Command
```powershell
# From project root: D:\Projects\aurevix
.\.venv\Scripts\streamlit.exe run dashboard/app.py
```
Access URL: `http://localhost:8501`

## Navigation
- Use the left sidebar to navigate across all 9 pages.
- Click **Refresh Telemetry** to purge cached data and refresh metrics live.
